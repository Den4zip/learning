Git-теги - метки, указывающие на конкретные коммиты в истории репозитория, обычно используются для маркировки версий релизов или важных этапов разработки. В отличие от веток, теги являются неизменяемыми ссылками на фиксированные точки в истории.
#### Есть два основных вида тега:

1. Аннотированные теги - хранят метаданные(имя автора, дату, сообщение, GPG-подпись), рекомендуются для публичных релизов.
2. Легковесные теги - ссылки на хеш коммита без дополнительной информации.

```
git tag <name>
```
Создание легковесного тега.

```
git tag -a <name> -m "message"
```
Создание аннотированного тега.

```
git show <tag_name>
```
Отображает информацию о теге и связанном коммите.


```
git tag -d <tag_name>
```
Удаляет тег из локального репозитория.

Теги не передаются на удалённый сервер. Для отправки используется: 

```
git push origin <tag_name>
```
```
git push --tags (для отправки всех тегов)
```
