1. Git - система контроля версий. Создана для упрощения разработки, записи
истории всех изменений и доработки функционала программы изолировано. 

2. Основой git являются ветки. Для основной версии программы используется
main/master,для экспериментов и фич создаются отдельные ветви, которые можно
затем слить с основной или удалить.

3. Для доступа к локальной истории git другим людям можно использовать
репозиторий github, Gitlab или Bitbucket.
