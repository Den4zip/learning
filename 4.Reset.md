```
git reset <commit>
```
Позволяет откатиться на несколько коммитов назад.
### Есть три флага для отката

#### 1. --soft

```
git reset --soft <commit>
```

Оставляет индекс прошлых коммитов и файлы в директории. Самый безопасный способ, так как файлы из прошлых коммитов остаются, история также сохраняется.

#### 2. --mixed

```
git reset --mixed <commit>
```

Оставляет только индекс прошлых коммитов, но не файлы в директории. Используется по умолчанию, тоже безопасен, нужен если разработчик решил изменить в коммите другие файлы.

#### 3. --hard

```
git reset --hard <commit>
```

Удаляет индекс и файлы внутри коммитов, коммиты исчезают полностью. Самый небезопасный.

## Git revert

```
git revert <commit>
```

Делает новый коммит, но уже с инвертированными изменениями. Позволяет отменять изменения в общедоступных или в отправленных ветках.

При конфликте слияния, можно его разрешить, и продолжить операцию командой.

```
git revert --continue
```

Отменить операцию.

```
git revert --abort
```
