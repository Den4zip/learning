```
git diff
```
Показывает изменения в рабочей директории, которые ещё не добавлены в индекс.

```
git diff --staged(или --cached)
```
Отображает изменения, которые были добавлены в индекс и готовы к коммиту. 

```
git diff <commit1> <commit2>
```
Сравнивает два конкретных коммита или ветки.

## Blame
```
git blame <file>
```
Выводит историю изменения для всех строк файла.

```
git blame -L xx,xx <file>
```
История изменений с диапазоном строк(xx,xx).

```
git blame -w <file>
```
Флаг игнорирования пробелов.
