```
git stash
```
Команда, сохраняющая изменения в рабочей директории и индексе, позволяя вернуть дерево файлов изменения в рабочей директории и индексе, также позволяя вернуть дерево файлов в чистое состояние, не создавая при этом новый публичный коммит. Это полезно для срочного переключения веток или исправления критических ошибок, когда текущая работа не готова к фиксации.

```
git stash(или git stash push)
```
Сохраняет текущие изменения.

```
git stash list 
```
Отображает все сохранённые стеши с их идентификаторами.

```
git stash apply 
```
Возвращает изменения, оставляя запись в списке.

```
git stash pop
```
Применяет изменения и удаляет их из стека.

```
git stash drop 
```
Удаляет конкретный стеш.

```
git stash clear
```
Очищает весь стек.
