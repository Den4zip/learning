```
git config
```
Используется для получения и установки параметров конфигурации, управляющие поведением и внешним видом Git. Эти настройки применяются на трех уровнях:
системном(--system, для всех пользователей), глобальном(--global, для текущего пользователя),локального(--local, для конкретного репозитория). 
```
git config --global user.name="name of user"
git config --global user.email="example@hotmail.com"
```
Создаёт локального пользователя git.

```
git config --list
```
Просмотр всех настроек.

```
git config --global --edit
```
Редактирование глобального файла.

```
git config list --show-origin
```
Поиск источника значения.

Глобальные настройки обычно хранятся в файле `~/.gitconfig` (или `~/.config/git/config` в системах с поддержкой XDG), а локальные — в `.git/config` внутри директории репозитория. Локальные настройки имеют приоритет над глобальными, а глобальные — над системными.
