```
git bisect
```
Инструмент для отладки, использующий алгоритм бинарного поиска для быстрого нахождения ошибок в коде. Он работает путем последовательного разделения истории коммитов пополам до тех пор, пока не будет найден конкретный «виновный» коммит.
## Принцип работы:

```
git bisect start
```
Начать отладку.
Git предлагает промежуточный коммит, который нужно протестировать. С помощью команд ниже можно отделить нужные коммиты.

```
git bisect good
```
Пометка коммита как хорошего.

```
git bisect bad
```
Пометка коммита как плохого.

```
git bisect reset
```
Возвращение к исходной ветке.

## Bisect run

```
git bisect run <script>
```
Автоматизация с помощью скрипта.
