## 1.Иницилизация
```
git config --global user.name="name of user"
git config --global user.email="example@hotmail.com"
```
Создаёт локального пользователя git.[[14.Config]]

```
git --version
```
Показывает версию git на устройстве.

```
git init
```
Создаёт локальный репозиторий и файл .git.

```
git add .
```
Добавляет все файлы из директории в индекс.

```
git commit -m "CommitText"
```
Выполняет коммит и с помощью флага "-m" записывает его описание.

```
git remote add origin "https://github.com/login/rep-name.git"
```
Подключаемся к удалённому репозиторию на github.

```
git branch -a
```
Проверяем в какой ветке находимся через флаг -a.

```
git push -u origin main
```
Пушим изменения на github. Флаг -u соединяет локальный и удалённый репозиторий, позволяя пушить изменения упрощённо без указания удалённого репозитория командой git push.
```
git status
```
Отображает текущее состояние рабочей директории и области индексации, показывая какие файлы изменены, добавлены или не отслеживаются.

## 2.Команды для работы с ветками

```
git branch 
```
Посмотреть все ветки, создать ветку, удалить ветку.
[[8.Branch]] 

```
git checkout <branch_name>
```
Переключиться на другую ветку, восстановить файл до определённого коммита.
[[7.Checkout]]

```
git pull
```
Получить информацию об изменениях с удалённого репозитория и подтянуть их в локальный репозиторий.

```
git switch
```
Переключиться на другую ветку.
[[7.Checkout]]
