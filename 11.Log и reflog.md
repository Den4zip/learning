```
git log
```
Отображает историю коммитов в репозитории.

```
git log --oneline
```
Компактный вид, где каждый коммит занимает одну строку.

```
git log --graph
```
Графическое отображение структуры веток и слияний.

```
git log -p
```
Показ подробных изменений(diff) для каждого коммита.

```
git log <file>
```
История изменений для конкретного файла.

```
git log --all 
```
Просмотр истории всех веток.

## Reflog

```
git reflog
```
Локальный журнал, фиксирующий все изменения указателей, а не только историю коммитов. Хранится частная историю действий пользователя на локальной машине. Инструмент является ключевым средством средством восстановлением данных, так как позволяет вернуть коммиты, удалённые ветки или отменить неудачные операции. Записи в reflog сохраняются локально в течение 90 дне(по умолчанию), после чего они могут быть удалены мусорным сборщиком(garbage collector), если на них не ссылается ни одна ветка.
