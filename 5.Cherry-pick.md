```
git cherry-pick <commit_hash>
```

Позволяет взять изменение из предыдущих коммитов и создаёт новый коммит с этим изменением.
Используется, например, чтобы взять исправление бага из одной ветки и добавить его в главную ветку. 

Без создания коммита

```
git cherry-pick -n <commit_hash>
```

После разрешения коммитов

```
git cherry-pick --continue
```
