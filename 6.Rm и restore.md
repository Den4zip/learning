```
git rm <file>
```
Удаляет файл из репозитория и диска, сразу сохраняя изменения

```
git rm --cached <file>
```
Удаляет файл только из индекса, оставляя его в рабочей директории. Полезно для файлов, которые не нужно отслеживать, но они нужно локально(файлы .gitignore).

```
git rm -r <directory>
```
Рекурсивно удаляет папку и её содержимое из репозитория и файловой системы.

---

## Restore

```
git restore <file>
```
Отбрасывает изменения в рабочем файле.

```
git restore --staged <file>
```
Убирает файл из индекса, не трогая рабочий каталог
